# assets
Original game assets only (`.claude/rules/asset-management.md`). Every file is registered in `ASSET_REGISTER.md`.

| Folder | Owner |
|---|---|
| `models/fighters/` | Character |
| `models/environment/` | Rendering |
| `textures/` | Rendering (fighter textures: Character) |
| `animations/` | Animation |
| `audio/` | Animation (integration); source TBD (OQ-17) |
| `effects/` | Rendering |

Greybox assets go in a `greybox/` subfolder of the relevant category.
