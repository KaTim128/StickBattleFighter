# Collaboration rules (Master Developer and specialists)

- The Master Developer assigns work; specialists do not self-assign or widen scope.
- **One owner per system** (`docs/workflow/SYSTEM_OWNERSHIP.md`). Write only inside assigned paths. Need something elsewhere? Stop and report it to the Master.
- **No concurrent edits** to the same file or system by two specialists. The Master checks the Active Assignments table before assigning.
- `package.json`, lockfiles, tsconfig, build and test config, `src/core/` and root docs: Master Developer only.
- Never overwrite, revert or "clean up" another specialist's work. Raise it instead.
- Read-only specialists (Architecture, QA) never edit files.
- Report with the WORKER COMPLETION REPORT format. Report failures and limitations honestly; never claim unverified success.
- **The Froggy project is read only** for everyone. Reference material is studied, never copied (spec §2).
