# Reference usage rules

Applies to all work on movement, combat, characters, abilities, animation, VFX, UI and level design (spec §2).

- **Creature Clash (Froggy):** read-only design reference for free arena movement, cover and line of sight, AI behaviour, and *ability concepts* (delivery types, effect categories, ultimate design philosophy). It is a 2D top-down game (TD-011), so it is no reference for the 3D camera or vertical movement. Never copy, import or modify its code, data, names, art or sound.
- **Stickman Kombat 2D:** high-level combat-readability reference only (timing, combo pacing, defensive choices, tutorial clarity). Never a reason to move toward side view or lanes. The title is unconfirmed (OQ-01).
- **Owner videos (Pokémon fan games):** presentation principles only (anticipation, impact, hit reactions, VFX readability, ultimate beats). **Stickman Arena is not a Pokémon game.** Never use Pokémon names, creatures, move names, type system, effectiveness messages, evolution, Poké Ball imagery, UI layouts, fonts, music or sound.
- Any adaptation must fit the five-action layout (INV-9) and stay fully 3D (INV-1).
- Reference research is written up as an observation report (`/reference-observation`). The Master Developer decides adoption.
- Never claim to have inspected a reference you could not access. State the limitation.
