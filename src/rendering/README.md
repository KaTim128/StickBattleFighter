# src/rendering
**Owner:** Rendering Specialist (2D). PixiJS 2D renderer, quality tiers, y-sorted draw order, filters, render interpolation. Reads simulation state; never mutates it.
- `house-furniture.ts` / `house-decor.ts` (Hide and Seek): the Nightmare House's modelled, aged furniture and its wall and floor dressing; `house-view.ts` assembles the cutaway and `occlusion-fader.ts` fades what stands in front of the player.
