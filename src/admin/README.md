# src/admin
**Owner:** Master Developer (tooling). The Character Editor (`admin.html`, TD-039): a local, validated editor for character JSON with an animation and hit-area preview. Nothing is published from it: export the JSON and commit it. Server-side admin tooling arrives with the backend (Phase 14, REQ-BE-4).

**Try in game** saves the draft locally and opens it in the training yard; the **Opponent** selector (owner, 12/11/2026, admin preview only) picks who it fights, any built-in character (`?opponent=<id>`).
